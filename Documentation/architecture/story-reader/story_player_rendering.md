# Story Player Rendering Architecture

How story presenter types consume Story data, drive audio playback, and render UI.

## Presenter Types

- **StoryBookPresenter** — prose scroll + word highlighting
- **DialogBookPresenter** — dialog script bubbles & character portraits
- **AudioBookPresenter** — podcast-style playlist
- **ComicBookPresenter** — panel grid + auto page turns
- **PictureBookPresenter** — full-screen swipe spreads
